# Agent 工作流开发

## 开发问的问题

1. 目标：为了解决什么问题
2. 用户
3. 触发方式：怎么启动流程
4. 输入输出
5. 现有流程是什么
6. 工具权限
7. 自主程度，哪些是要人工确认的
8. 成功标准
9. 异常处理
10. 约束

逐步拆分，一直问来补充开发细节
