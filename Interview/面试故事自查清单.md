# 面试故事自查清单

来源：《如果面试官只和你说真话》（MrJonathan职场教练，2026-09-23，BV1uphk6jE3E）

核心原则：面试官想听的不是"做了什么"（what），而是"为什么这么做"（why）。

## 使用前

每个故事（项目经历）按以下 6 项逐条检查。任何一项答不出，就回到材料里补充。

## 6 项检查

### 1. 背景（Context）
- [ ] 能否用 1–2 句话说清：谁、在什么情况下、为什么要做这件事
- [ ] 听众不听追问就能听懂开头的来龙去脉

### 2. 角色真实（Role）
- [ ] 描述的职责与本人实际做的事一致，无夸大
- [ ] 如果用了"主导""负责"这类词，能说清具体决策权和执行范围
- [ ] 夸大之前先想：面试官（未来的经理）清楚这个级别该做什么

### 3. 决策与取舍（Why）
- [ ] 每个关键动作都能回答"为什么这样做"
- [ ] 能说清做过哪些取舍（trade-offs）、考虑过哪些备选方案
- [ ] 不是照念步骤清单——清单类内容 AI 也能给，面试考察的是思考过程

### 4. 挑战（Challenge）
- [ ] 故事里有一个真实的难点：反对意见、脏数据、紧的时间线、资源不足，至少一个
- [ ] 能描述困难有多大、自己怎么应对
- [ ] 没有挑战的故事没有说服力（困难越大，越能体现能力）

### 5. 影响力（Impact）
- [ ] 结果不止"完成、大家满意"
- [ ] 短期：推动了哪个具体指标（数字 + 单位）
- [ ] 长期：对客户 / 经理 / 公司高层分别有什么价值，按对象分层说清楚

### 6. 反思（Reflection）
- [ ] 能回答"重来一次会改什么"，且答案具体
- [ ] 不是"没有"。被追问三次才答出来会减分

## 一句话模板

背景 + 我的真实角色 + 关键决策与取舍 + 遇到的挑战 + 分对象的影响力 + 一条具体反思

## 反面信号（出现即打回重写）

- 以"我们"开头却说不清自己做了什么
- 只有步骤、没有原因
- 一路顺利、毫无阻碍
- 结果只到"交付物"为止
- "没什么可改进的"
